# Переходная архитектура (Transition Architecture: MVP -> 12 Months)

Стратегия перехода гарантирует, что созданный к 15 октября код **не выбрасывается и не переписывается**, а органично эволюционирует по мере роста бизнеса.

---

## Эволюционные состояния платформы

```
  [СОСТОЯНИЕ 0: СЕЙЧАС] ──────► [СОСТОЯНИЕ 1: MVP (15 ОКТ)] ──────► [СОСТОЯНИЕ 2: 6 МЕСЯЦЕВ] ──────► [СОСТОЯНИЕ 3: 12 МЕСЯЦЕВ]
  - Нет кода и команды          - Модульный монолит (Go)            - Вынос PII Vault в Лагос          - Микросервисы (K8s/EKS)
  - 29 фичей в бэклоге          - 5 ключевых capabilities           - USSD-канал для мерчантов         - 15 стран Африки
  - Бюджет $5k, 8 недель        - AWS ECS Fargate ($2 000/мес)      - 50 000 заказов / день            - 500 000 заказов / день
                                - RDS Multi-AZ + Redis кэш          - Расширение эквайринга            - Event Streaming (Kafka)
```

---

## Матрица эволюции архитектурных компонентов

| Компонент / Домен | Состояние 1: MVP (Запуск 15 Октября) | Состояние 2: Стабилизация (6 Месяцев) | Состояние 3: Целевая архитектура (12 Месяцев) | Причина изменений и триггер |
|---|---|---|---|---|
| **Архитектурный стиль** | **Модульный монолит** (Go / Single Container per Task на AWS ECS Fargate). | **Модульный монолит** с горизонтальным масштабированием (Auto-scaling 3–10 подов). | **Гибридная микросервисная архитектура** на базе AWS EKS (Kubernetes). | Рост нагрузки свыше 100 000 заказов/день и расширение команды разработки до 20+ человек. |
| **Каталог и поиск (Catalog)** | Go Module внутри монолита + кэш Redis (TTL 15 мин) + Postgres Trigram Search. | Внедрение **OpenSearch / Elasticsearch** для автодополнения и морфологии на 5 языках. | Выделенный **Catalog Microservice** с независимой БД и CDN кэшированием. | Объем SKU превышает 500 000 позиций; нагрузка на чтение достигает 2 000 RPS. |
| **Процессинг платежей** | M-Pesa Daraja API + Flutterwave + COD в рамках единого модуля `Payment Engine`. | Автоматическая маршрутизация платежей (Smart Routing) между Flutterwave и Paystack. | Выделенный **Payment & Ledger Microservice** с поддержкой мультивалютных кошельков. | Выход в 15 стран с локальными валютами (NGN, KES, ZAR, GHS, UGX, TZS). |
| **База данных** | Единый кластер **AWS RDS PostgreSQL Multi-AZ** с логическим разделением на схемы. | Multi-AZ RDS Postgres + 2 выделенные **Read Replicas** для отчетов и витрины. | Паттерн **Database-per-Service** (отдельные базы данных для Orders, Catalog, Billing). | Изоляция транзакционной нагрузки и независимое масштабирование схем. |
| **Персональные данные (PII)** | Изолированный модуль `PII Vault` в защищенной подсети AWS Cape Town. | Физический вынос `PII Vault` на локальный VPS в дата-центр **MainOne (Лагос)** по NDPR. | Мульти-региональный `PII Vault Network` (Нигерия, Кения, ЮАР, Египет). | Официальные предписания регуляторов защиты данных соответствующих стран. |
| **Шина событий / Очереди** | In-Memory Channels (Go) + Redis Pub/Sub для задач уведомлений. | **AWS SQS / RabbitMQ** для гарантированной доставки асинхронных задач. | **Apache Kafka / AWS MSK** для потоковой обработки доменных событий и CDC. | Необходимость сквозной аналитики и интеграции десятков микросервисов. |
