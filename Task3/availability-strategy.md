## 2. Ключевые архитектурные паттерны отказоустойчивости

### 2.1. Паттерн постепенной деградации (Graceful Degradation)
В случае частичного отказа внешних систем или пиковой перегрузки ядро платформы не падает, а переходит в защищенный режим:
1. **Сбой платежного шлюза M-Pesa / Банков**:
   - Интерфейс автоматически скрывает недоступные методы онлайн-оплаты и переключает покупателя на **Cash on Delivery (Оплата наличными при получении)**;
   - Заказ сохраняется в статусе `PENDING_OFFLINE_PAYMENT` без блокировки корзины.
2. **Перегрузка базы данных PostgreSQL**:
   - Чтение каталога перенаправляется на **Redis Cache** и **CDN Stale Cache** (отдача закэшированного каталога с пометкой о возможной задержке обновления остатков);
   - Неотложные транзакции заказов буферизуются во встроенную in-memory очередь с постепенным сбросом в БД (Rate Limiting).
3. **Сбой шлюза SMS-нотификаций (Africa's Talking)**:
   - Сообщения складируются в локальную очередь `Retry Queue` с экспоненциальной задержкой (Exponential Backoff);
   - Покупателю на фронтенде отображается статус заказа в реальном времени через веб-интерфейс.

### 2.2. Защита от каскадных сбоев (Circuit Breaker & Rate Limiting)
- Все исходящие вызовы к внешним API (M-Pesa, Africa's Talking, курьерские службы) оборачиваются в **Circuit Breaker** (библиотека `gobreaker` / `resilience4j`):
  - При 50% ошибок за 10 секунд контур переходит в состояние `OPEN` (мгновенный возврат fallback-ответа без ожидания таймаута);
  - Через 30 секунд контур переходит в `HALF-OPEN` для проверки восстановления провайдера.
- На уровне API Gateway внедрен **Token Bucket Rate Limiting** (не более 20 RPS на IP-адрес для предотвращения парсинга и DDoS).

### 2.3. Инфраструктурная избыточность (Infrastructure Redundancy)
- **Compute**: 3 реплики приложения на AWS ECS Fargate, распределенные по 3 зонам доступности (AZ-a, AZ-b, AZ-c) в регионе `af-south-1` (Кейптаун) за Application Load Balancer;
- **Database**: AWS RDS PostgreSQL Multi-AZ (автоматический синхронный Standby инстанс в соседней зоне, failover $< 60$ с без потери данных);
- **Read Scalability**: Выделенная Read Replica для аналитических запросов и формирования отчетов.
